# Linger

**A private, local-first visual reference library for macOS.**

Keep the image, its source, and the reason it mattered. Linger brings visual references and personal notes together so you can return to an idea when you need it.

[Website](https://withlinger.com/) · [Browser demo](https://withlinger.com/demo/) · [Creator](https://www.linkedin.com/in/lucius-miao-820b57429/)

## Status

**Documentation checked: October 28, 2026.** The macOS application is in private validation; public installer distribution is currently paused. The browser demo is available, but does not prove desktop installation, account access, or MCP connectivity. Use the [website](https://withlinger.com/) for current availability.

This repository contains public documentation and illustrative requests. Linger's application source remains private, and this repository does not include an installer or model weights.
