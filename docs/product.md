# Product and availability

Linger is a private, local-first design reference library for macOS, created by Lucius Miao at BlackHarbor Analytics Limited. Keep the image or excerpt, where it came from, and what made it worth saving.

## A reference workflow

1. **Collect.** Import, drag in, or paste local images. Use the Chrome extension to save supported media, a page link, an article, or selected text. Saved article text depends on what can be extracted from the source page.
2. **Add context.** Keep source links, personal notes, and tags alongside each reference. Optional machine-generated descriptions have their own fields.
3. **Return to an idea.** Browse the visual wall or grid, search stored text, or use structured Recall filters (Beta). Experimental on-device image recall requires separate setup. Optional external model connections are off by default.
4. **Arrange references.** Use persistent project canvases (Beta) to group and compare references in the local library.

## Platform and availability

- The native app requires an **Apple Silicon Mac with macOS 14 or later**. The interface uses AppKit and SwiftUI, and a shared Rust core manages the SQLite-backed library. Each Mac keeps its own library, without built-in cloud sync or a shared multi-user library.
- [Download Linger](https://withlinger.com/download) and sign in by email to start a **7-day full trial**. No payment card is required. Eligible accounts can extend the trial once for another seven days in the app. After expiry, access to existing originals, notes and source links, basic search, and export is retained.
- Regular one-time prices are **Personal at $39 USD** for one person on up to two Macs, with one year of updates and optional renewal for future updates, and **Lifetime at $79 USD** for one person on up to four Macs, with future desktop updates included. Both let you keep using the versions covered by the license. See [pricing and licenses](https://withlinger.com/pricing/) for current offers and terms.
- The [browser demo](https://withlinger.com/demo/) uses curated sample references and temporary demo state. Install the desktop app to use your library, native file handling, and its [local MCP server](mcp.md).

See [data and privacy](data-and-privacy.md) for how local storage, sign-in, and optional model providers work together.
