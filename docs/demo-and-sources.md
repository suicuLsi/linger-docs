# Demo image and sources

The image in this repository is the existing screenshot used on Linger's public website:

- Original: [website library screenshot](https://withlinger.com/assets/product-demo/wall-1280.webp)
- Interactive context: [browser demo](https://withlinger.com/demo/)
- Artwork metadata and credits: [demo provenance](https://withlinger.com/demo/provenance.json)

The screenshot shows the browser demo with curated museum reference content. It is not a private user library, a desktop installation test, or evidence that every illustrated feature is available in a publicly distributed build. The demo uses temporary sample state.

The artwork provenance lists The Metropolitan Museum of Art object pages, image sources, and public-domain status as checked for the demo on October 26, 2026. Artwork ownership and credits remain distinct from Linger's interface. No museum endorsement is implied.

This repository includes the screenshot only, not a downloadable collection of the source artwork. The labels and collections in the demo are example content.
